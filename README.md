# Guess The Number

This is a **mini-game** where we have to guess a number randomly chosen by the computer.

## 📝 Description 

I have used **IntelliJ IDEA** to implement this game. It is played in **console mode**.  

The goal of this game is to guess the number randomly generated by the computer between 0 and 100.
I called this number `solutionNumber`.

The user does the number input, and the program will display a message indicating if the number is
bigger, smaller or if the user has won (guess the right number).

**A few rules :**  
- The user can play up to 10 games. He chooses at each end of game if he wants to continue
playing or not.  
- The user has 5 attempts each game.
- The score is the number of attempts left at the end of a game. 
If the user find the `solutionNumber` at the first attempt, the score of this game is 10.
- The final score is the addition of the scores of all the games played.

**The program control if the user's inputs are valid :**
- The number input must be between 0 and 100.
- When the user decides if he wants to continue playing, 
the only accepted characters are `n` and `y`.
